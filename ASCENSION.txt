OCARINA OF TIME (ASCENSION)
==========================

Release 1.3 | Apple silicon Mac | macOS 26.6 or later

Ascension is a macOS build of Ocarina of Time for Switch 2, based on
nxnative. It includes a pre-launch settings window, native HDR10 on
supported displays, MetalFX scene reconstruction, Match Display aspect
ratio, and optional experimental frame generation. Frame generation
falls back to rendered frames when its requirements are unmet.

INSTALL
-------
1. Install full Xcode with the Metal Toolchain. Use the Xcode 27.2
   toolchain recorded in the project or the supported Xcode 27.3 compiler.
2. Set up Homebrew tools once: brew install python zstd glslang
   Use Apple silicon Python 3.14 or later.
3. Download Ascension-Installer.zip from the README on the
   ascension-1.3-public branch. Unzip it and open Ascension Installer.app.
4. Select your complete OOT Switch 2 NUP, choose a folder, and click
   Build & Install. The supported title is 0400486024DEC000, update v131072.

Set aside about twice the NUP size plus 10 GiB, with extra room for
compilation if needed. The first build can take several hours. Internet
access is used to install the Python build packages. The installer
builds the game locally using your NUP. The ZIP includes the installer
and build tools. A compatible Ascension update keeps existing saves
and settings in their normal locations.

VERIFICATION
------------
The installer was signed, checked against a v131072 NUP, and tested
for first install and in-place replacement with signed test bundles.
A complete first build through Metal shader compilation is pending
verification with the required Xcode Metal Toolchain.
